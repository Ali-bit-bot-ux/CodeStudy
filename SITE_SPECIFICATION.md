## 4. Строгие правила дизайна (Правила, которые нельзя нарушать)

1. **Правило глубины и контраста (Dark Cyber EdTech):**
   - Базовый фон: ультра-темный графит `#090D16` / `#0D111D`.
   - Запрещен плоский чистый черный цвет `#000000` без градиентов или свечений.
   - Карточки строятся на базе Glassmorphism: `backdrop-filter: blur(14px)`, `background: rgba(18, 24, 38, 0.72)`, тонкая рамка `border: 1px solid rgba(255, 255, 255, 0.08)`.

2. **Правило видео-фона (Video Overlay Guard):**
   - Запрещено пускать текст поверх открытого видео без защитной маски.
   - Обязателен двойной слой затемнения: радиальный градиент по центру + вертикальный градиент с переходом в фоновый цвет сайта.
   - Обязателен CSS-fallback (анимированная сетка кода / кибер-градиент), если видеофайл еще не подгружен или не поддерживается.

3. **Правило типографики:**
   - Заголовки: **Plus Jakarta Sans** / **Outfit** (веса 700, 800) — плотные, энергичные.
   - Текст: **Inter** (веса 400, 500) с комфортным межстрочным интервалом `line-height: 1.6`.
   - Код и чипы: **JetBrains Mono** — ощущение настоящего IT.

4. **Правило одного клика до конверсии (Zero-Friction CTA):**
   - Главная кнопка действия всегда ведет на WhatsApp (+7 771 292 7393) с автоматически заполненным сообщением.
   - Кнопки не должны быть меньше `48px` в высоту для удобного нажатия со смартфонов.

5. **Правило микро-анимаций:**
   - Никаких "мертвых" блоков: карточки плавно реагируют на курсор (`translateY(-5px)`, мягкое свечение границ), кнопки имеют упругий отклик (`transform: scale(0.98)` при нажатии).
